# 🕌 مشغل القرآن الكريم — Quran Player

مشغل ويب عربي للاستماع إلى التلاوات مع عرض نص القرآن بالرسم العثماني والترجمة الإنجليزية، مع دعم التثبيت كتطبيق ويب تقدمي (PWA).

## المزايا
- استعراض القرّاء والروايات المتاحة عبر MP3Quran API.
- تشغيل السور والتحكم بالتشغيل والسرعة والتنقل.
- عرض النص العثماني والترجمة الإنجليزية (Sahih).
- إبراز الآية الحالية والتنقل إليها.
- تنزيل التلاوة بصيغة MP3.
- دعم التثبيت والعمل دون اتصال جزئياً عبر Service Worker وذاكرة التخزين المؤقت.
- واجهة عربية متجاوبة للهواتف والحواسيب.

## التشغيل المحلي
يتطلب المتصفح اتصال HTTPS أو localhost لتفعيل Service Worker.

```bash
python -m http.server 8000
```

ثم افتح http://localhost:8000.

## النشر على GitHub Pages
المستودع يتضمن سير عمل GitHub Actions في `.github/workflows/deploy.yml`. بعد رفع الملفات، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر. بعد نجاح سير العمل سيكون الموقع متاحاً على:

https://BMHEA58.github.io/quran-player/

## مصادر البيانات
- التلاوات والقرّاء: [MP3Quran](https://mp3quran.net)
- نص القرآن والترجمة: [AlQuran Cloud](https://alquran.cloud)

## ملاحظات
- التصفح الأول يتطلب اتصالاً بالإنترنت لتحميل قائمة القرّاء والنصوص والتلاوات.
- التخزين دون اتصال يعتمد على ما تم تحميله أو تخزينه مؤقتاً مسبقاً.
- تُعرض الترجمة الإنجليزية لأغراض المساعدة، ويظل النص العربي هو الأصل.
